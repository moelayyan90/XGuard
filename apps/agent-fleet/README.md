# أسطول الوكلاء المحلي

يشغّل هذا التطبيق مهام لوكلاء ذوي تعليمات وأدوات محددة باستخدام نموذج لغوي محلي، ويحفظ طابور العمل والنتائج وحالات التنفيذ في SQLite. العدد الافتراضي **2000 تعريف وكيل**؛ ينفّذ المهام **4 عمّال متزامنين** افتراضيًا، ويتشاركون خادم النموذج المحلي.

تعريف 2000 وكيل لا يعني تشغيل 2000 عملية أو 2000 نموذج في الوقت نفسه. كما أن إنجاز مهمة أو إنشاء ملف لا يثبت بيعًا أو إيرادًا. لا توجد في هذا التطبيق أداة دفع، أو شراء، أو تداول، أو إرسال رسائل للآخرين.

## المتطلبات

- Node.js 24 أو أحدث، وPython 3 لتنزيل أصول الاستدلال المثبتة.
- يدعم برنامج الإعداد المرفق Linux على x86_64. يمكن تشغيل خادم llama.cpp محلي متوافق بصورة منفصلة على الأنظمة الأخرى.
- اتصال إنترنت لتنزيل المحرك والنموذج مرة واحدة؛ ملف النموذج يقارب 639 MB.
- موارد جهاز كافية لتشغيل Qwen3-0.6B-Q8_0 بواسطة CPU. سرعة الجهاز والذاكرة تؤثران على زمن التنفيذ.

الإصدارات وروابط المصدر وأحجام الملفات وبصمات SHA-256 مثبتة في `models.lock.json`. يتحقق برنامج الإعداد منها قبل اعتماد الملفات. رخصة النموذج Apache-2.0 ورخصة llama.cpp هي MIT؛ تُراجع شروط أي أصول إضافية على حدة.

## التشغيل من جذر المستودع

نزّل المحرك والنموذج ثم أنشئ التعريفات:

```bash
python3 apps/agent-fleet/scripts/setup-local.py
node apps/agent-fleet/cli.mjs init --count 2000
node apps/agent-fleet/cli.mjs status
```

أضف مهمة ثم شغّل دفعة محدودة مع خادم النموذج التابع لها:

```bash
node apps/agent-fleet/cli.mjs enqueue --agent agent-000001 --task 'اكتب قائمة فحص قصيرة لاكتشاف التكرار في بيانات CSV دون اختلاق نتائج.' --key csv-checklist-1
node apps/agent-fleet/cli.mjs run --with-model --limit 10 --concurrency 4
node apps/agent-fleet/cli.mjs status
```

يشغّل `--with-model` محرك llama.cpp كعملية تابعة، ويتولى إيقافه عند انتهاء الدفعة أو إيقاف خادم التحكم. يميز مفتاح المهمة `--key` الإرسال المتكرر. استخدم مفتاحًا جديدًا للمهمة المختلفة. تظهر معرفات المهام والنتائج في مخرجات الأوامر ولوحة التحكم.

لعرض تعريفات الوكلاء:

```bash
node apps/agent-fleet/cli.mjs agents --limit 100 --offset 0
```

## إسناد مهمة لعدة وكلاء

يسند `assign` التكليف إلى كل وكيل يطابق المرشحات، مع تعليمات تخصصه المحفوظة. يمكن اختيار الدور والمجال والسوق، وتقليل عدد الخطوات وحجم الإجابة:

```bash
node apps/agent-fleet/cli.mjs assign --task 'اكتب قائمة تحقق قصيرة لقبول ملف أمر عمل مطبعة، وفق تخصصك، مع بيان ما يحتاج إلى معلومات من العميل.' --limit 2 --role documentation_writer --sector print_production --max-steps 2 --max-output-tokens 256 --key print-checklist-1
```

تُضاف `--market jordan` عند الحاجة إلى نطاق الأردن فقط. لإسناد تكليف مشترك إلى الأسطول كله:

```bash
node apps/agent-fleet/cli.mjs assign --task 'من منظور تخصصك، اقترح مخرجًا صغيرًا مفيدًا يمكن التحقق منه لهذا المجال والسوق، وحدد البيانات المطلوبة دون اختلاق عملاء أو دخل.' --limit 2000 --key fleet-initial-work-1
```

هذا الإسناد يضع المهام في الطابور؛ لا يدعي تنفيذها. إعادة الأمر بالمفتاح نفسه والتكليف والحدود نفسها لا تنشئ نسخة إضافية للوكيل نفسه. حقل `assigned` يحصي المهام المطابقة، بما فيها الموجودة سابقًا؛ استخدم `status` لمعرفة المجموع الفعلي وحالات الإنجاز. أي تكليف جديد يحتاج مفتاحًا جديدًا. يرفض التطبيق تغيير نص المهمة مع إعادة استعمال مفتاحها.

طلبات الويب محجوبة افتراضيًا. عند إسناد بحث إلى وكيل يملك `web_get`، حدّد نطاقات HTTPS المسموحة صراحة:

```bash
node apps/agent-fleet/cli.mjs run --with-model --limit 10 --concurrency 4 --allow-domains docs.apify.com,developers.cloudflare.com
```

يقبل أمر `serve` الخيار نفسه، ويمكن استخدام `FLEET_ALLOWED_DOMAINS` بدلًا منه. السماح بالنطاق لا يمنح الأداة لوكيل لا يملكها أصلًا. تُمنع العناوين الخاصة والمحلية وإعادة التوجيه؛ هذه حدود أمان للقراءة، وليست تفويضًا بشراء أو استخدام خدمة مدفوعة.

## لوحة التحكم وجدولة العمل

```bash
node apps/agent-fleet/cli.mjs serve --with-model --port 8790
```

افتح `http://127.0.0.1:8790`. يشغّل هذا الأمر واجهة التحكم المحلية. لتشغيل مجدول الطابور معها:

```bash
node apps/agent-fleet/cli.mjs serve --with-model --port 8790 --watch --concurrency 4
```

ينفذ المجدول المهام المتاحة بالدفعات وبحدودها؛ وجود تعريفات بلا مهام لا ينتج عملًا تلقائيًا. يتطلب التشغيل المتواصل بقاء العملية الرئيسية وطفل النموذج يعملان. يوقف زر الإيقاف في الواجهة جدولة دفعات جديدة، ويلغي التشغيل الجاري بإشارته؛ اعرض حالة المهام لمعرفة ما اكتمل وما حُجب أو فشل.

إذا انقطع النموذج أو رُفض اعتماده أو نفدت ميزانيته، تتوقف الدفعة عن سحب مهام إضافية، وتبقى المهام غير المسحوبة في الطابور. يوقف المجدول التلقائي نفسه أيضًا عندما تُحجب دفعة كاملة. ذاكرة التخزين المؤقت للمحرك محدودة بـ256 MiB؛ لا تُترك قيمة llama.cpp الافتراضية 8192 MiB داخل هذا التشغيل.

إذا أردت إدارة النموذج في طرفية منفصلة، استخدم `model-start` ثم احذف `--with-model` من أوامر `run` و`serve` حتى لا تبدأ محركًا ثانيًا على المنفذ نفسه:

```bash
node apps/agent-fleet/cli.mjs model-start --port 8080
```

لا تُحوّل هذه الأوامر مساحة العمل المؤقتة إلى استضافة دائمة، وقد تتوقف العمليات أو تُزال الملفات عند انتهاء البيئة. احفظ المشروع ونسخة الحالة على جهاز أو خادم دائم إذا أردت تشغيلًا مستمرًا.

## الحالة وحدود التنفيذ

تُحفظ الحالة افتراضيًا في `.state` داخل مجلد التطبيق. يمكن تحديد مسار آخر بواسطة `FLEET_STATE_DIR` أو خيار `--state`. احفظ قاعدة SQLite وملفات النتائج معًا عند نقل التشغيل.

يستخدم العميل `FLEET_MODEL_URL`، وقيمته الافتراضية `http://127.0.0.1:8080`. يقبل اتصال النموذج عنوان loopback فقط؛ لا يرسل الطلبات إلى OpenAI أو أي مزود استدلال سحابي. ينشئ التشغيل اعتمادًا محليًا للموديل في `.runtime/model.key`؛ هذا ليس مفتاح OpenAI، ويجب إبقاؤه خارج Git والمهام والملفات المنشورة. لا تضف مفاتيح حسابات أو محافظ إلى المهام أو ملفات النتائج.

| العنصر | الحد الافتراضي |
|---|---:|
| تعريفات الوكلاء عند الإنشاء | 2000 |
| عمّال الدفعة المتزامنون | 4 |
| مهام أمر `run` الواحد | 10 |
| خطوات النموذج لكل مهمة، شاملة الإعادات | 4 |
| أقصى رموز مخرجات الطلب الواحد | 256 |
| ميزانية استدعاءات النموذج اليومية للأسطول | 2000 |
| محاولات تنفيذ المهمة | 3 |
| طلبات قراءة الويب اليومية للأسطول | 100 |
| طلبات قراءة الويب لكل مهمة | 3 |

يمكن تقليل حدود المهمة. السقف المدعوم هو 8 خطوات و1024 رمز مخرجات لكل استدعاء، ويبقى سقف العمال المتزامنين 4. لا تعني ميزانية 2000 استدعاء محلي يوميًا ضمان إمكانية إنجازها بسرعة أو ضمان جودة مخرجاتها.

تُحجز ميزانية الاستدعاء قبل إرسال الطلب للنموذج، ويُحسب اليوم بتوقيت UTC. إعادة المحاولة لا تصفّر عدد الاستدعاءات المستخدمة. انتهاء حجز عامل لا يمنحه الحق في إكمال مهمة انتقلت إلى عامل آخر.

| الحالة | معناها |
|---|---|
| `queued` | تنتظر عاملًا |
| `running` | عامل يملك حجزًا صالحًا وينفّذها |
| `done` | أُنتجت نتيجة وحُفظت |
| `failed` | فشل التنفيذ أو نفدت المحاولات |
| `blocked` | أوقفتها السياسة أو الميزانية أو غياب اعتماد لازم |

تقتصر أدوات العمل على الكتابة والقراءة داخل مساحة المهمة وطلبات ويب مقيدة حسب الصلاحيات. النص الآتي من المهمة أو النموذج أو أداة الويب محتوى غير موثوق؛ اجتياز صلاحيات الأدوات وحدود المسار والشبكة يُفحص في الكود، ولا يكفي أن يطلبه النموذج.

## الاختبارات وما تثبته

```bash
node --test apps/agent-fleet/test/*.test.mjs
```

تختبر CI على Node.js 24 التخزين والحجوزات والميزانيات وحدود الأدوات والشبكة وخادم التحكم. اختبارات runtime تستخدم نموذجًا حتميًا بديلًا للتحقق من مسار التنفيذ والفشل والإعادة؛ نجاحها لا يثبت أن نموذج Qwen المحلي كان يعمل أو أن نتائج المهمات صحيحة دلاليًا. لا تُنزّل CI النموذج ولا تستدعي خدمة مدفوعة.

اختبار CLI ينشئ 2000 تعريف في SQLite من خلال عمليات أوامر فعلية، ثم يثبت إسناد مهمتين ومنع تكرارهما؛ لا يشغّل LLM. إثبات الاستدلال الفعلي يتطلب تشغيل خادم النموذج وإتمام مهمة معه وفحص الملف الناتج. تبقى أعداد الوكلاء والمهام الناجحة والتعثرات قابلة للفحص عبر `status` وقاعدة الحالة؛ يجب الإبلاغ عما رُصد بالفعل.

يوفر `node apps/agent-fleet/scripts/qualify-local.mjs 2000` جولة تهيئة فعلية بالنموذج المحلي: ينشئ تكليفًا قصيرًا لكل اختصاص ويحفظ مخرجاته وتقريرًا في `.state/qualification-report.json`. هذه الجولة تطلب اقتراح مخرج ومعيار تحقق، وتحد نص الجواب بـ80 محرفًا. ليست تنفيذ أعمال خارجية أو فحص استعداد عملاء للشراء. لا يُعد اختبار وجود كلمتي «التسليم» و«التحقق» تحققًا من صحة المضمون.

Qwen3-0.6B نموذج صغير؛ قد يكون بطيئًا على CPU وقد ينتج إجابات خاطئة أو محدودة أو تنتهي عند سقف الرموز. حالة `done` تثبت حفظ مخرج، ولا تثبت صحته أو اكتمال متطلبات عميل. لا يعتمد عليه لإثبات معاملة مالية أو إيراد؛ تلك تحتاج سجلات موثقة مستقلة.

لا توجد رسوم API سحابية في مسار النموذج المحلي، لكن وقت الجهاز والكهرباء والاستضافة تكاليف مستقلة لم تُحسب هنا. الربط بقنوات بيع أو تنفيذ أعمال مدفوعة للآخرين يحتاج تكاملًا وصلاحيات وشروط قبول وتحصيل مستقلة؛ هذه النسخة لا تصنع طلب شراء بمجرد زيادة عدد التعريفات.
